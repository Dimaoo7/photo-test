# Photographer Portfolio

Портфолио фотографа на Astro и Tailwind CSS.

## Команды

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Страницы

- `/` — главная страница и избранные истории
- `/portfolio` — список фотосессий
- `/albums/[slug]` — отдельная галерея с загрузкой фото

Данные альбомов находятся в `src/data/albums.ts`. Демонстрационные фотографии подключены с Unsplash и заменяются на реальные ссылки при наполнении проекта.
